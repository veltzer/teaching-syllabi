# `AI`-Ready Documentation: The Missing Layer in `AI`-Assisted Development

**Technical leadership expert talk.** How to give `AI` coding agents the context they need to
deliver better results.

## The Challenge
`AI` coding agents can read code, but they do not automatically understand your team's
conventions, architecture, development workflows, or constraints. Without reliable context,
they can make confident but incorrect assumptions - slowing delivery and undermining trust
in `AI`-assisted development.

## What This Session Covers
A practical, technical introduction to documentation designed for `AI`-assisted software
development: what to document, how to structure agent-facing project guidance, and how to
keep that guidance useful as the codebase evolves.

## Agenda
* **Why `AI` Needs Better Documentation** (15 min): How missing project context leads to errors, hallucinations, and inconsistent output.
* **From Traditional Docs to `AI`-Ready Context** (20 min): The difference between human-oriented documentation and guidance `AI` agents can use.
* **Agent Instructions and Project Rules** (25 min): `CLAUDE.md`, `AGENTS.md`, `.cursorrules`; conventions, build/test workflows, guardrails, and anti-patterns.
* **Documenting Large Codebases** (20 min): Approaches to complex systems; where parsers and retrieval-augmented generation (`RAG`) can complement documentation.
* **Keeping Documentation in Sync** (15 min): How to keep documentation aligned with code and changing engineering practices.
* **Is Your Documentation Actually Helping?** (15 min): Ways to assess documentation quality and its effect on `AI` output.
* **Key Takeaways and Q&A** (10 min): Actionable next steps for engineering teams.

## Takeaways
* A clear understanding of why documentation is critical for reliable `AI` coding workflows
* Familiarity with agent instruction files
* A practical framework for identifying gaps, maintaining context, and evaluating documentation effectiveness

## Who Should Attend
* Engineering managers
* Tech leads
* Software architects
* Developers adopting `AI` coding assistants

## Continue the Journey
This talk introduces the foundations. A follow-on, hands-on workshop can apply the concepts
to the team's own repositories, project conventions, agent instructions, and documentation
workflows.
