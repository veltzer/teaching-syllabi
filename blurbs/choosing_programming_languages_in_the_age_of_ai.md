# Choosing Programming Languages in the Age of `AI`

**Technical leadership expert talk.** When `AI` agents write much of the code, the old
criteria for choosing a programming language no longer hold. What matters now, and what
should your next project be written in?

## The Challenge

Teams have always chosen languages by weighing productivity, learning curve, hiring,
performance, and ecosystem. `AI` coding agents change almost every one of those factors.
Verbose languages are no longer slow to write, difficult languages are no longer as hard to
adopt, and rewriting a system in another language is no longer unthinkable. At the same time,
new factors appear: how well agents know a language, how much a compiler can catch before a
human ever reads the code, and how easy the result is to review. Choosing by the old rules
risks the wrong choice for the next decade.

## What This Session Covers

A practical, technical look at language selection when much of the code is produced by `AI`
agents: which traditional criteria lose their weight, which new criteria emerge, how type
systems and tooling become verification for agent output, and how cheap rewrites change
long-term technology strategy.

## Agenda

* **The Question Has Changed** (10 min): The classic criteria for choosing a language, and which of them `AI` agents weaken or overturn.
* **What the Agent Knows** (15 min): Why agents write popular languages better than niche ones, and what that means for new, rare, and in-house languages.
* **The Compiler as a Reviewer** (20 min): Static types and strict compilers as a first line of verification for agent output; what `TypeScript` and Rust catch that `Python` and `JavaScript` do not.
* **Verbosity and Learning Curves Revisited** (15 min): When boilerplate costs nothing to write and hard languages become approachable, which old objections still matter.
* **Written by Agents, Read by Humans** (15 min): Readability and ease of review as the new bottleneck, and the language features that help or hurt review.
* **Tooling and the Feedback Loop** (15 min): Fast builds, lint tools, test runners, and clear error messages as the loop agents use to correct themselves.
* **Rewrites Become Affordable** (20 min): Migrating legacy systems such as `COBOL` or aging `C++` with `AI`; when a rewrite is now the right call and how to keep it safe.
* **Key Takeaways and Q&A** (10 min): A practical checklist for choosing a language for your next project.

## Takeaways

* A clear understanding of how `AI` agents change the trade-offs between programming languages
* New criteria for language selection: agent proficiency, compile-time verification, ease of review, and tooling
* A practical framework for language choices, migrations, and long-term technology strategy
